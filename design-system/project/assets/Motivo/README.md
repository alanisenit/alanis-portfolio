# Motivo

El asterisco de ocho brazos de Alanis, en archivos SVG de una sola tinta (el color está dentro del archivo).

- `asterisco-rosa.svg` — tinta `pink` (#FF7EA6). Logotipo y acentos sobre `night`.
- `asterisco-miel.svg` — tinta `honey` (#FFC94D). Stickers y separadores de la cinta.
- `asterisco-azul.svg` — tinta `blue` (#2D62C4). Sobre paneles claros y al centro del sticker.
- `asterisco-verde.svg` — tinta `green-lite` (#7FE0B5). Acentos sobre `night`.

En la web, preferir el símbolo `#ast` en línea (componente Asterisk) para que tome el color con CSS.
