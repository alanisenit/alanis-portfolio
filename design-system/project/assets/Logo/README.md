# Logo

Enit Designs, versión “Arma tu noche”. Las tintas van dentro de cada archivo.

- `enit-designs-color.svg` — logo principal a color, fondo transparente.
- `enit-designs-una-tinta-noche.svg` — una tinta `night` (#0A0F20) con letras caladas, para fondos claros.
- `enit-designs-una-tinta-blanca.svg` — una tinta blanca con letras caladas, para fondos oscuros y fotos.
- `enit-designs-monograma.svg` — la E sobre `night`, para favicon y avatares.
- `enit-designs-color-1000.png`, `enit-designs-monograma-512.png` — versiones en mapa de bits.

El kit completo (PDF, JPG, PNG en varios tamaños, avatares e íconos) está en `marca/enit-designs/` del repositorio.
