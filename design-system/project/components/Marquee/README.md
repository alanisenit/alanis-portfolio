# Marquee

Cinta que desliza nombres de marcas y organizaciones con asteriscos de colores entre ellos.

- **Provee:** solo nombres verificados del CV y el portafolio (Century 21, Socohua, Jakon CRM, Otro Maldito Podcast, Brigham Young School, Cumorah Academy), escritos dos veces para que el bucle no tenga cortes; la segunda copia con `aria-hidden="true"`.
- 40 s por vuelta, se pausa al pasar el mouse y se detiene con `prefers-reduced-motion`.
- Va sobre `night`, al final del hero. Sin logotipos de terceros.
