# Chip

Píldora con borde `ink` para listas cortas de herramientas o idiomas en paneles claros.

- `pn-chip-on` (relleno `ink`) marca las principales: Photoshop, Illustrator, InDesign y los dos idiomas.
- **Provee:** una a tres palabras por chip, sin iconos.
- No es un filtro ni un botón: para filtrar usa los #hashtags de `Filters`.
