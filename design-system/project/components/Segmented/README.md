# Segmented

Selector de dos opciones en cajas, usado para "Soy marca o empresa / Soy creador/a" al inicio del formulario de contacto.

- **Provee:** dos `input type="radio"` con el mismo `name` y sus `label`. La opción elegida va en `honey` con barra inferior `ink` de 4px.
- Solo para dos opciones excluyentes que cambian el resto del formulario. Para más opciones, usa un `select`.
