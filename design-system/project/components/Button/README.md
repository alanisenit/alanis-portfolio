# Button

Botón en píldora con texto `button` en mayúsculas; el verde con relieve es la acción principal de cada vista.

- **Variantes:** `pn-btn-green` (principal, texto `on-green`, relieve `press-green`), `pn-btn-honey` (descargar CV, relieve `press-honey`), `pn-btn-ghost` (secundario sobre `night`), `pn-btn-outline` (secundario sobre paneles claros), `pn-btn-ink` (dentro de paneles claros), `pn-btn-white` (sobre paneles de color).
- **Provee:** un verbo primero ("Ver trabajo", "Escribir a Alanis", "Proponer una colab") y, opcional, una flecha `i-arrow` al final.
- Un solo verde por vista. Nunca texto blanco sobre `green`: no llega a 4,5:1.
- Al pasar el mouse los botones con relieve bajan 3px (`dur-quick`, `ease-pop`).
