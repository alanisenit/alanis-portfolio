# ServiceRow

Fila de servicio dentro del panel azul: etiqueta, nombre grande, descripción y una flecha que gira al pasar el mouse.

- **Provee:** categoría (`Tag` con #), nombre del servicio, una frase de beneficio y el enlace a la página del servicio o al trabajo filtrado (`/trabajo#f-branding`).
- Cinco filas como máximo: Redes sociales, Branding, Diseño editorial, Ilustración, Video corto.
- Al pasar el mouse la fila se desplaza 14px y la flecha pasa a `honey`. Bajo `bp-lg` se apila en tres líneas.
