# Tag

Etiqueta rectangular de categoría: el color dice qué tipo de trabajo es, el texto lo confirma.

| Categoría | Clase | Fondo | Texto |
| --- | --- | --- | --- |
| Redes sociales | `pn-t-redes` | `blue` | `on-blue` |
| Branding | `pn-t-branding` | `green` | `on-green` |
| Editorial | `pn-t-editorial` | `pink` | `ink` |
| Ilustración | `pn-t-ilustracion` | `honey` | `ink` |
| Fotomontaje | `pn-t-fotomontaje` | `lav` | `ink` |
| Video corto | `pn-t-video` | `green-lite` | `ink` |

- **Provee:** el nombre corto de la categoría; con `#` delante en ventanas, casos y servicios.
- Esquinas rectas (`radius-none`). En una tarjeta va solo la categoría principal; en la ventana, todas.
- No inventar colores para categorías nuevas: proponer el cambio en este sistema primero.
