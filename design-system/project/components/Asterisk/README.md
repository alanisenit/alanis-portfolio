# Asterisk

El motivo de la marca: un asterisco de ocho brazos con trazo irregular, dibujado a mano en el portafolio de Alanis. De noche es estrella; junto a las piezas, una flor.

- **Provee:** un `svg` con `<use href="#ast">` (símbolo con el filtro `rough`) dentro de `span.pn-ast`; el color sale de `color`.
- Colores permitidos: `pink` (logotipo), `honey`, `green-lite`, `blue-lite` sobre `night`; `blue` o `ink` sobre paneles claros; `white` dentro del sol verde.
- Tamaños de 16px (botón Hablemos) a 190px (sol del cierre). Puede girar despacio (`pn-spin`, 14–22 s) y seguir al mouse con paralaje de 10–70px.
- No rellenar, no cambiar el número de brazos, no usar emoji ✳️ en su lugar. Los archivos sueltos están en el grupo Motivo.
