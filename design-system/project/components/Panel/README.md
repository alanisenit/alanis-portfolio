# Panel

Hoja redondeada (`radius-lg`) donde vive el contenido, separada de las demás por `space-3` sobre el fondo `night`.

| Variante | Uso | Texto |
| --- | --- | --- |
| `pn-panel-white` | Rejillas de trabajo, casos, preguntas | `ink`, `muted` |
| `pn-panel-paper` | Texto largo: Sobre mí, Contacto | `ink`, `ink-soft` |
| `pn-panel-blush` | Presentación de Alanis | `ink`, `blue` |
| `pn-panel-blue` | Servicios | `on-blue` |
| `pn-panel-green` | Colaboraciones con creadores | `on-green` |

- **Provee:** un `pn-p-head` (titular a la izquierda, entradilla o botón a la derecha) y el contenido.
- Relleno vertical `clamp(40px, 6vw, 84px)`, lateral `space-7` (`space-4` bajo `bp-md`), a 10px del borde de la ventana.
- El trabajo de Alanis solo va en `white` o `paper`. No poner dos paneles de color seguidos.
