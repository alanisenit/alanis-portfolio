# CtaCard

Tarjeta de llamada del cierre: un camino para marcas (`honey`) y otro para creadores (`pink`).

- **Provee:** rótulo `overline` ("Para marcas y empresas"), titular `display-block` ("Cuéntame tu proyecto") y una línea de detalle; toda la tarjeta es el enlace.
- Siempre en pareja y en este orden. Texto `ink` en ambas. Al pasar el mouse sube 4px y gira −0,6°.
- También en `mint` o `sky` para navegación entre casos.
