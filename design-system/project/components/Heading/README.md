# Heading

Titular condensado en mayúsculas con, como máximo, un acento a mano: el gesto que reconoce la marca.

- **Estructura:** `pn-d` + tamaño (`pn-h1` página, `pn-hero` inicio, `pn-h2` sección, `pn-h3` bloque) y opcional un `span.pn-hand` con una a tres palabras.
- Sobre `night`: titular `cream`, acento `pink` o `green-lite`, y una palabra del titular puede ir en `green-lite`. En paneles claros: titular `ink`, acento `blue` (nunca `pink` ni `honey` como texto).
- Escribir el texto en tipo oración en el HTML; las mayúsculas las pone el CSS (mejor para lectores de pantalla y SEO).
- Un `h1` por página con la palabra clave principal ("Diseño que se queda en tu feed" va acompañado de "Diseñadora gráfica freelance" en el antetítulo).
