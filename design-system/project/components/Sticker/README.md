# Sticker

Sticker circular `honey` con texto en curva "DISPONIBLE ✶ FREELANCE" y un asterisco `blue` al centro; gira en 22 s.

- Uno por página como máximo, en el collage del hero o junto al retrato. Decorativo: `aria-hidden="true"`; la disponibilidad también se dice en texto (antetítulo con el punto `green-lite`).
- **Provee:** el texto en mayúsculas (máximo ~40 caracteres en la curva, `textLength` 430).
- Si Alanis no está disponible, quitar el sticker en lugar de cambiar su texto.
